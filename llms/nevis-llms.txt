# Nevis

> Nevis (Nevis Security AG) is a Swiss customer identity and access management (CIAM) and passwordless authentication provider. The Nevis Authentication Cloud adds passwordless login and transaction signing to applications using FIDO2 passkeys, the Nevis Access App device authenticator, OATH TOTP, SMS OTP and recovery codes, via a versioned REST API and native iOS / Android Mobile Authentication SDKs.

## APIs

- [Nevis Authentication Cloud REST API](https://docs.nevis.net/authcloud/api-doc/api-reference/): Passwordless registration, authentication and transaction signing; served per instance under https://{instance}.mauth.nevis.cloud/api/v1
